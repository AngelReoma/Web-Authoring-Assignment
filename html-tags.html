Explaining HTML Tags

Purpose and Use, Key Attributes and Support Webrowser

HTML Tags Purpose & Use Key Attributes Support Webrowser
<img> tag is used to embed an image in an HTML page the src attribute specifies the path to the image to be displayed fully supported by all mordern browsers
<html> the lang> inside the <html> tag, declare the language of the Web page country code can also be added in the lang attribute fully supported by all mordern browsers
<title> define some extra information about an element title attribute will be define as tooltip fully supported by all modern browser
<a> efines a hyperlink. attribute of <a> is href attribute which indicates link destination fully supported by all modern browsers
<body> defines the document's body, and is a container for all the visible contents, such as headings, paragraphs, images, hyperlinks, tables, lists, etc. <body> supports the global attributes fully supported by all modern browsers
<tables> defines an HTML table <table> consist one or more <tr> <th> and <td> elements fully supported by all modern browsers
<ul> tag defines an unordered (bulleted) list <ul> tag with <li> tag create an unordered list fully supported by all modern browsers
<p> defines a paragraph browsers authomatically add a single blank line before and after each <p> element fully supported by all modern browsers
<h1-4> element defines heading <h1> defines the most important heading. <h5> defines the least important heading browser automatically add margin before and after heading
