# Web Authoring Assignment

This project is a small static website exploring the evolution of HTML and CSS, and the relationship between the two technologies in modern web design.

## Project files

- `index.html` — main HTML page about the history and evolution of HTML
- `css.html` — page focused on CSS development and styling concepts
- `html-tags.html` — HTML tag reference and examples
- `reference.html` — reference material for the assignment
- `style.css` — shared stylesheet used across the website
- `img/` — image assets used in the pages

## How to view the site

Open `index.html` in a browser to view the website locally.

## Notes

This is a front-end assignment built with plain HTML and CSS, without frameworks or build tools.
