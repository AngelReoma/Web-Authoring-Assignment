Evolution of HTML from 2.0 to HTML 5.1

HTML has come a long way since Tim Berners-Lee invented it in 1989. It has evolved over the years from early versions

from HTML 2.0 to modern HTML5 standard.

The Different Versions of HTML:

  • HTML 2.0
  • HTML 3.2
  • HTML 4.01
  • HTML5.1

HTML2.0: The first standard

By 1995, the web had gained enough traction that standardization became necessary.
HTML 2.0 became the first official specification published by the Internet Engineering Task Force (IETF).

HTML3.2

HTML 3.2 emerged in 1997 as a compromise standard from the newly formed World Wide Web Consortium (W3C).
It incorporated many of the extensions that had became widely used:

HTML4.01

HTML 4.01 released in 1999 marked a philosophical shift in web development.
The key innovation was the formal separation of structure (HTML), presentation (CSS) and behaviour (Java Script).

HTML5.1

HTML5 became the formal recommendation in 2014 in which represented a revolution in web capabilities.
In 2016 HTML5.1 has been officially released in W3C Recommendation.

Summary of HTML Versions and their key changes.

Versions Year Released Key Changes
HTML2.0 1995 This version added new features such as (e.g "forms","input","select","images" and "head")
HTML3.2 1997 This version added tables, scripts, and unfortunately, lots of visual markup like "font" and "center".
HTML4.01 1999 Minor bug fixes to HTML4.0. As HTML4.01 remained the standard for 15 years.
HTML5.1 2016 Adding updates such as "picture" for responsive images and "dialogue" for modal dialogs.
